# Лунная Логистическая Сеть (Moon Rover Control Center)

Moon Rover Control Center — это интерактивная экономическая веб-стратегия на базе FastAPI и React (TypeScript, Vite), симулирующая управление логистическим парком автоматизированных роверов на Луне.

---

## Как запустить проект

Все сервисы проекта полностью контейнеризированы и готовы к запуску одной командой.

### 1. Требования
* Установленный **Docker** и **Docker Compose**.

### 2. Запуск
В корневом каталоге проекта выполните команды:
```bash
docker-compose up --build
```
```bash
docker compose exec backend python -m app.db.seed
```
Это запустит три контейнера:
1. `db`: База данных PostgreSQL 16 (порт `5432`).
2. `backend`: Сервер API на FastAPI (порт `8000`).
3. `frontend`: Клиентское веб-приложение на Vite + TS (порт `80`).

После запуска откройте в браузере: **`http://localhost`** (или `http://localhost:80`).

## Что сделано и основные возможности

1. **Интерактивная карта Луны:** Масштабируемая и перетаскиваемая SVG-карта с отображением станций, маршрутов и роверов в реальном времени. Реализован умный зум, не затрагивающий прокрутку основной страницы.
2. **Флот роверов и Ангар:** Мониторинг заряда батареи, текущего износа, брони и грузоподъёмности каждого юнита.
3. **Экономическая модель:** За каждую выполненную миссию игрок получает лунные кредиты (**CR**) и очки репутации. Кредиты можно тратить на ремонт изношенной техники или расширение флота.
4. **Магазин роверов (Rover Shop):** Возможность покупать новые роверы различных классов (от лёгких разведчиков до тяжелых броневиков Behemoth-MAX) с уникальными характеристиками.
5. **Цель игры и Game Over:** Игроку необходимо балансировать интересы фракций. Если репутация с **любой** из трёх фракций упадёт **ниже 20**, наступает поражение. Добавлен наглядный баннер поражения с возможностью перезапуска игры одной кнопкой.
6. **Выбор роверов перед отправкой:** Прямо в форме формирования миссии добавлен селектор роверов, позволяющий оценить их готовность (заряд, износ) перед назначением на маршрут.
7. **Тестирование и Качество:** Проект покрыт тестами на 90%+ (включая API роверов, станций, карт и навигационных сервисов).

## Логика ключевых игровых механик

### Влияние веса груза на доставку
Масса перевозимого заказа напрямую влияет на эффективность доставки:
* **Энергопотребление:** Масса груза вводит повышающий коэффициент на расход батареи. Ровер, загруженный на максимум, расходует в **2 раза** больше энергии.
* **Физический износ:** Тяжелый груз создает дополнительное напряжение на ходовую часть, пропорционально увеличивая износ на маршруте.
* **Награда:** За доставку тяжелых грузов выплачивается значительно больше кредитов и начисляется больше очков отношений.

### Влияние опасных зон и риска (Hazard Risk)
Карта разделена на зоны с разным уровнем опасности (`hazard_risk` от 0% до 100%):
* **Замедление движения:** Опасные рельефы замедляют ровер. Маршрут с высоким риском может увеличить время в пути в 2 раза.
* **Механический износ (Wear):** Перемещение по опасным зонам наносит урон роверу. При достижении **100% износа** ровер ломается (статус `damaged`) и требует ремонта.
* **Броня ровера (Armor):** Бронирование ровера снижает наносимый износ. Тяжёлые роверы лучше подходят для разведки опасных регионов.

### Соперничество фракций и Влияние Станций
* **Бонус Домашней Станции:** Репутационная награда увеличивается в **1.5 раза**, если ровер принадлежит станции, контролируемой той же фракцией, что и цель доставки.
* **Дипломатическое Соперничество:** При росте репутации с целевой фракцией, репутация с конкурирующими фракциями автоматически снижается (механика `Factions_relationship`).

## Хранение данных (PostgreSQL)

* **`station`:** Баланс игрока, суммарная репутация и лимит ангара.
* **`factions`:** Профили лунных объединений.
* **`station_faction_reputation`:** Текущие отношения (0–100) игрока с каждой фракцией.
* **`maps` / `route_segments`:** География Луны и характеристики путей.
* **`rover`:** Детальные характеристики, состояние и местоположение юнитов флота.
